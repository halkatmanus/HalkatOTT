# Third-party code

`app/src/main/java/com/termux/**` and `app/src/main/cpp/termux.c` are the unmodified (except for one `R` import
path) `terminal-emulator` and `terminal-view` libraries from https://github.com/termux/termux-app (tag v0.118.0),
which are derived from Android-Terminal-Emulator by Jack Palevich and are licensed under the Apache License 2.0
(see Apache-2.0.txt). The rest of the termux-app repository is GPLv3 and is NOT included here.
